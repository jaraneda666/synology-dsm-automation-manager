# Synology Manager — Documentación

Repositorio dedicado a la gestión, automatización y seguridad de Synology NAS (`192.168.1.100`).

## Estructura
- `/tools`: Scripts y herramientas de auditoría y gestión de Synology (y enlaces a herramientas compartidas en OpenWrt_Manager).
- `/scratch`: Scripts de diagnóstico y utilidades de ejecución temporal.
- `/output/backups`: Respaldos de configuraciones de Reverse Proxy, firewall e iptables.
- `/skills`: Roles especializados de agentes.
- `/memory`: Registro de aprendizaje continuo y catálogo de tools.
